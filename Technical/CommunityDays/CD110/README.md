# Silent Superpowers: Why Breaking Production Isn’t Scary Anymore

**Session:** CD110 | **Speaker:** [André Silva](https://dotnet.microsoft.com/en-us/conf/2026/speakers/andre-silva)

[Session details](https://dotnet.microsoft.com/en-us/conf/2026/agenda/brk109) | [Download the slides](CD110.pdf)

## Abstract

Feature flags let teams deploy code independently from when users see new functionality. This session explores gradual rollouts, canary releases, and experimentation with OpenFeature, an open, vendor-neutral standard for feature flagging. The demo combines Aspire with the flagd integration to show how these practices can help teams release changes with greater confidence.
