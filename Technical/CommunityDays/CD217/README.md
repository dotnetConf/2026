# Building Oracle AI Apps with .NET and EF Core 11

## Alex Keh

.NET 11 and Oracle AI Database 26ai introduce new features for AI development. We'll explore EF Core 11 support for VECTOR_SEARCH(), vector indexes, and more. Discover how seamlessly the new Oracle AI Database Vector Store Connector integrates with native .NET vectors and Microsoft Agent Framework. Watch how Oracle Deep Data Security helps provide least-privilege access for agentic AI from .NET applications without any app code changes. See all these capabilities in action through demos.
