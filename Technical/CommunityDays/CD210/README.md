## SE.Redis in .NET 11

Content for _"SE.Redis in .NET 11"_ by [@mgravell](https://github.com/mgravell).

# Abstract

> Redis is a foundational piece of tech in many applications, and SE.Redis is the primary library
> for talking to Redis from .NET, either directly or via tools like asp.net caching, Hybrid Cache,
> Fusion Cache, etc. Here we: - have a quick look at new exciting features in SE.Redis like
> client-side-caching, active-active, etc for richer applications - look at how SE.Redis 4.0 uses
> new C#/.NET features to create a new hyper-efficient API, while trivially supporting the pre-existing API
