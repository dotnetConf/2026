# Building the future of agentic UI with Blazor

**Session:** BRK023 | **Speaker:** [Daniel Roth](https://dotnet.microsoft.com/en-us/conf/2026/speakers/daniel-roth)

[Session details](https://dotnet.microsoft.com/en-us/conf/2026/agenda/brk023) | [Download the slides](<Building the future of agentic UI with Blazor.pptx>)

## Abstract

As AI agents move from answering questions to reasoning over context, using tools, and taking action, the needs of modern web UI are changing. Free-form chat remains a powerful and flexible foundation, but agentic applications must also communicate progress and tool activity, connect conversations to structured interfaces, synchronize shared state, request human decisions, and keep users in control. In this session, we'll explore the emerging patterns shaping agentic UI and how .NET and the Microsoft stack support them. Through live demonstrations, see how the experimental Blazor AI components, the open AG-UI protocol, Microsoft Agent Framework, Microsoft Foundry, and Aspire work together to enable streaming interactions, custom tool experiences, human-in-the-loop workflows, and shared application state. Learn how these pieces fit together and what they mean for the next generation of web development with Blazor.
