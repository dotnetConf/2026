# Less Chat, More Action: AI-Powered .NET MAUI Apps

Connect AI to the features of an existing .NET MAUI app with Microsoft.Extensions.AI and experimental tooling from .NET MAUI Labs. Expose app actions as AI-callable tools, keep the conversation and UI in sync, and keep users in control.
