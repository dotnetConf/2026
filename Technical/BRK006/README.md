# What's New in .NET MAUI in .NET 11

A tour of what's new in .NET MAUI for .NET 11: the move to CoreCLR, XAML source generation, C# expressions in XAML, XAML Incremental Hot Reload, Material 3 on Android, `dotnet run`/`test`/`watch` for devices, and AI-assisted development with .NET MAUI Labs.
