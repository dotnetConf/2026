# Protect your PC from AI coding agents while modernising legacy .NET apps

**Session:** BRK035 | **Speaker:** [Justin Yoo](https://dotnet.microsoft.com/en-us/conf/2026/speakers/justin-yoo)

[Session details](https://dotnet.microsoft.com/en-us/conf/2026/agenda/brk035) | [Download the slides (PDF)](sandboxing-app-modernisation.pdf) | [Download the slides (PowerPoint)](sandboxing-app-modernisation.pptx)

## Abstract

Have you experienced or heard that AI coding agents accidentally removed files or directories, or accessed to resources that you didn't allow? It can happen from time to time. We can't get rid of this behaviour from our AI coding agents. However, we can isolate it from our PC. Throughout this session, I'm going to discuss a couple of options how we can isolated or sandbox AI coding agents from our main PC while performing .NET app modernisation through the modernisation plugins of GitHub Copilot CLI.
