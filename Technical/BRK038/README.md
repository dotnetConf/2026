# Test Smarter: AI-Assisted Testing for Modern .NET

**Session:** BRK038 | **Speaker:** [McKenna Barlow](https://dotnet.microsoft.com/en-us/conf/2026/speakers/mckenna-barlow)

[Session details](https://dotnet.microsoft.com/en-us/conf/2026/agenda/brk038) | [Download the slides](test-smarter-ai-powered-testing-for-dotnet.pptx)

## Abstract

As AI accelerates software development, confidence in code quality becomes more important than ever. In this session, you'll learn how AI-powered testing workflows can help identify testing gaps, generate and improve tests, validate changes, and provide deeper insights into the quality of your code. Through practical demonstrations using Microsoft.Testing.Platform, MSTest, and modern .NET tooling, we'll explore how AI and proven testing practices work together to build software that developers can trust. You'll leave with concrete techniques for applying AI throughout the testing lifecycle while keeping humans in control of the final decisions.
