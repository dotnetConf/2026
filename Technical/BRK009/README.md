# What's New in Aspire for .NET Developers

**Speakers:** Maddy Montaquila and Damian Edwards

[Session details](https://dotnet.microsoft.com/en-us/conf/2026/agenda/brk009)

[Download the slides](DotNetConf-2026-AspireForDotNetDevs.pptx)

Explore how Aspire's expansion across programming languages is improving the .NET development experience, including capabilities available today and a look at what's coming next.
