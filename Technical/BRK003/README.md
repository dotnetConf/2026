# Moving `dotnet` Ahead (of Time)!

**Speaker:** Chet Husk

[Session details](https://dotnet.microsoft.com/en-us/conf/2026/agenda/brk003)

[Download the slides](native-aot-dotnet-cli.pptx)

In .NET 11, the `dotnet` CLI is a native app - it's snappy, responsive, and flexible! It took a lot of work to get there, and we learned about some 'gotchas' along the way, so we want to show you our process so that you can make excellent NAOT apps too!
