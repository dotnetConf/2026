# Modern web development with ASP.NET Core & Blazor in .NET 11

**Session:** BRK002 | **Speaker:** [Daniel Roth](https://dotnet.microsoft.com/en-us/conf/2026/speakers/daniel-roth)

[Session details](https://dotnet.microsoft.com/en-us/conf/2026/agenda/brk002) | [Download the slides](<Modern web development with ASP.NET Core & Blazor in .NET 11.pptx>)

## Abstract

ASP.NET Core and Blazor in .NET 11 deliver improvements across the web stack, driven by developer feedback and the demands of large-scale production services. In this demo-packed tour, we'll see how .NET 11 strengthens the platform fundamentals with advances in performance, security, and observability; increases productivity across Minimal APIs, SignalR, and Blazor; and makes it easier to build distributed and agentic web applications. We'll explore highlights including asynchronous validation, richer API contracts, more capable server-side rendering, scalable Blazor apps, deeper Aspire integration, and new building blocks for agentic user interfaces. Whether you build APIs, interactive web applications, or AI-enabled experiences, you'll leave knowing how .NET 11 helps you build faster, more reliable, and more ambitious web applications.
