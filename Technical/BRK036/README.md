# Blazor Server in .NET 11: Fast, resilient, and scalable

**Session:** BRK036 | **Speaker:** [Daniel Roth](https://dotnet.microsoft.com/en-us/conf/2026/speakers/daniel-roth)

[Session details](https://dotnet.microsoft.com/en-us/conf/2026/agenda/brk036) | [Download the slides](<Blazor Server in .NET 11 - Fast, resilient, and scalable.pptx>)

## Abstract

Great web apps need to load quickly, remain responsive, preserve user state through interruptions, and scale efficiently as demand grows. Blazor in .NET 11 expands its flexible server rendering model, which combines static server-side rendering with Blazor Server interactivity using the same component model. Static SSR now supports more application scenarios, including client-side validation, temporary data, session state, and output caching, allowing more experiences to run without an interactive circuit. Where rich interactivity is needed, persistent component state and circuit pause and resume make Blazor Server more resilient and scalable by avoiding duplicate work, preserving sessions across disconnections, freeing resources for inactive users, and supporting graceful deployments. See how these capabilities work together to help you build responsive, resilient web experiences that scale efficiently to support more users.
