# How Aspire uses .NET to build an agent-first toolchain for any programming language

**Speakers:** Maddy Montaquila and Jose Perez Rodriguez

[Session details](https://dotnet.microsoft.com/en-us/conf/2026/agenda/brk013)

[Download the slides](DotNetConf-2026-HowAspireUsesDotNet.pptx)

Explore how Aspire uses .NET technologies including Blazor, Native AOT, and code generation to build a toolchain for developers and coding agents across programming languages.
