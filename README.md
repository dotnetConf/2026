# .NET Conf 2026
Branding, content and demos for the .NET Conf 2026 event, hosted by [Microsoft](https://dotnet.microsoft.com/en-us/) and our [Community Partners](https://dotnetconf.net)

## Repository layout

- `Creative/` contains event branding and presentation templates. The creative assets are designed to help promote the event across various platforms and media formats.
- `Technical/` contains session materials, including slides and demo content. See [`Technical/README.md`](Technical/README.md) for the session listing.
- `swag/` contains device wallpaper assets.
